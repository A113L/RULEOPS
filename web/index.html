CONCENTRATOR CORE
Markov pipelineUses the source's Kneser–Ney token model and crack-focused synthetic corpus before best-first rule generation.
Processing pipelineApplies selected filters in the original fixed order: minimum occurrence, top-N, functional minimization, inverse filter, then Hashcat cleanup.
Functional minimizationRemove rules with equivalent transformations using the source signature engine. If the source is large, enable high-memory confirmation; otherwise this step is safely skipped instead of prompting in the background.

RULEOPS ABOUT

About.

A free, local-first Hashcat rule toolchain for generating, ranking and refining rulesets.

✳
Local-firstGPU-accelerated toolchain
THE PROJECT

One toolchain, three workflows

RULEOPS brings RULEST, Rule Ranker and Concentrator together in one authenticated local interface. Processing runs on your machine and uses your available CPU and GPU resources, with a focus on efficient local workflows.

GPU acceleratedLocal processingCommunity-driven
TOOLCHAIN

What each program does

#
RULESTRule generation engine
  • Build optimized Hashcat rulesets from wordlists and cracked-password material
  • GPU-accelerated CELF selection for high target coverage with fewer rules
  • Tune Bloom filters, greedy vs frequency trade-offs, and multi-GPU runs
  • Safe pause / resume checkpoints for long generation jobs
⇧
Rule RankerScore & optimize rulesets
  • Score candidate rules against hashes or cracked sets
  • CELF-optimize an existing .rule file while preserving coverage
  • Analyze ranking CSVs and export cleaned or re-scored rules
  • GPU ranking and optimization; CSV analysis stays CPU-only
⌘
ConcentratorExtract, generate & clean
  • Frequency-ranked or Markov-weighted extraction from rule collections
  • Combinatorial token-chain generation with length and target bounds
  • Kneser–Ney Markov training and best-first rule generation
  • Normalize, deduplicate and refine large multi-file rule libraries
